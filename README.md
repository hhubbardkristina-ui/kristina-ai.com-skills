# kristina-ai.com-skills

A growing collection of Claude Skills, built and shared as I transition my 17-year-old recruitment company into an AI-native business. Each skill lives in its own folder with everything you need to install and use it.

## Skills in this repo

- **[storm](./storm)**, a five-perspective research method that catches the ways AI research quietly goes wrong: fabricated citations, overconfidence, agreeing with your framing, single-angle blind spots, and false consensus from repetition. See `storm/README.md` for what it does and how to install it.

## How to grab a skill (no coding experience needed)

1. Click the green **Code** button near the top of this page, then **Download ZIP**.
2. Unzip it and open the folder for the skill you want, for example `storm`.
3. Follow the install steps in that skill's own `README.md`.

More skills will be added here over time.
